## 算法逻辑

### 第一步：车辆去重 & 险种分类

**去重键**：`车牌号(col9) + 车架号(col27)` 同时相同 = 1辆车

**险种分类**（扫描同车多条记录）：
- 含商业险（col36）→ **交三**
- 只有交强险（无商业险）→ **单交强**

### 第二步：维度分类

每辆车根据以下规则逐行过滤，**每行独立统计**其保险公司出现次数（v8 恢复 v5 风格，详见「算法演进」段）：

> **v8 业务语义**：R3/R5/R6 通用维度（地址/身份证/年龄）与 R7-R26 细分维度（车型子分类）正交，一辆车可同时命中多个维度，每行独立 +1。**这不是"重复计入"，是"多维独立统计"**——同一辆行唐地址+25 岁车主的新能源客车新车，会被 R3、R6、对应 R7-R13 行**各计入 1 次**，反映该车在不同营销维度下的保司倾向。

#### 通用维度（行3-6）

| 行 | 维度 | 条件 |
|----|------|------|
| 3-4 | 行唐地址 | col14/18/21任一含"行唐" **或** col13/16/19前6位=130125 |
| 5 | 异地身份证 | col13前4位≠1301 |
| 6 | 25岁以下 | col12\|17\|20任一年龄<25岁 |

#### 客车维度（行7-13，col31=客车）

| 行 | 维度 | 条件 |
|----|------|------|
| 7 | 新车+过户 | 新能源(col40非燃油/燃气) + col24=新车 或 (col24空且初登<9个月) + 过户 |
| 8-9 | 旧车+非过户 | 新能源 + col24≠新车 + 非过户 |
| 9 | 企业 | 新能源 + col26=非营业企业 |
| 10 | 新车+非过户 | 燃油/燃气(col40) + 新车 + 非过户 |
| 11 | 旧车+过户 | 燃油 + 旧车 + 过户 |
| 12 | 旧车+非过户 | 燃油 + 旧车 + 非过户 |
| 13 | 企业 | 燃油 + col26=非营业企业 |

#### 货车维度（行15-28，col31=货车 且 核载质量<2吨）

核载质量判断：
- col33 > 40 → 先÷1000换算吨，再判断<2
- col33 ≤ 40 → 直接判断<2

细分（按col28车辆型号关键词）：
- 含"厢式"或"封闭式" → **厢货**
- 含"仓栅"或"仓栅式" → **仓栅**
- 含"自卸" → **自卸**
- 含"多用途" → **多用途**
- 其他 → **普货**

| 行 | 使用性质 | 车型 |
|----|------|------|
| 15-16 | 非营业(col26含"非营业"不含"营业") | 厢货 |
| 17 | 非营业 | 仓栅 |
| 18-19 | 非营业 | 多用途 |
| 20 | 非营业 | 自卸 |
| 21 | 非营业 | 普货 |
| 22-23 | 营运(col26含"营业") | 厢货 |
| 24 | 营运 | 仓栅 |
| 25 | 营运 | 自卸 |
| 26 | 营运 | 普货 |

> **2026-06-08 调整**：删除原 R25/R26「营运+多用途」2 行（该类组合数据源为空）。原 R27/R28 自卸/普货 → 现 R25/R26。总行数 28 → 26。

### 第三步：新车/过户判断

**新车（col24优先，回退col23）：**
- col24有值 → 直接用
- col24为空 → 距今<9个月=新车

**过户（col22优先，回退col23+col25）：**
- col22有值 → 直接用
- col22为空 → col23==col25 → 非过户
- col22为空且不一致 → 距今<365天=过户，否则=非过户

### 第四步：保险公司简称

去除后缀（财险/保险/在线/联合），保留核心名称：
人保、太平洋、平安、泰康、渤海、中华、众安、安盛天平、中航安盟等。

### 第五步：排序规则

按出现次数降序，取前8名填入I-P列（主推1-5→I-M，推荐6-8→N-P）。
次数相同按原始顺序（不额外排序）。

## 边界处理

- 某维度无数据 → 该行I-P列留空（不填`-`）
- 数据源不存在 → 报错"数据文件不存在"
- 车辆分类不匹配任何行 → 该车不计入

## 交付推送 (2026-06-08 新增)

输出 2 个 xlsx 后, **不要让主人去服务器下载**。走推送脚本:

```bash
/root/.openclaw/workspace/bin/push-to-user.sh \
  /root/.openclaw/workspace/单交保司推荐_$(date +%F).xlsx \
  /root/.openclaw/workspace/交三保司推荐_$(date +%F).xlsx
```

脚本自动:
1. xlsx → pdf → png (120 DPI, 多页) 到 `~/.openclaw/workspace/.push-out/`
2. 打印 6 个 MEDIA: 路径, agent 在回复中**全部贴上** (webchat 内联显示)
3. 打印 `openclaw cron add` 一键命令, agent **立即执行** 创建一次性 cron
4. 微信 cron (10秒后) 跑 agentTurn, agentTurn 把原件 xlsx 用 MEDIA: 推微信
5. cron `delete-after-run` 自动清理

> **不要忘了**: agentTurn 看到 message 里含 `MEDIA:file://...` 路径时, 会从 file:// 协议读本地文件, 转推 iLink。**直接拿原始 xlsx 推微信**, 微信客户端可下载, 不是转 PNG。
