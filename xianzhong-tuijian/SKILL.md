## 算法逻辑

### 第一步：车辆去重 & 多 rec 合并

**去重键**：`车牌号 + 车架号`，同车牌+车架的多条 rec 视为同一辆车。

合并每辆车的：
- `险种` 集合（含 交强险/商业险/驾乘人员意外伤害保险 等）
- `险别` 拼接（用于判定是否含"车损"/"机动车损失保险"）

### 第二步：险种判定（per 车辆）

| 条件 | 客车险种 | 货车险种 |
|------|---------|---------|
| 交强险，无商业险 | 单交 | 单交 |
| 交强险 + 商业险，险别无车损 | 交三 | — (非联合单) |
| 交强险 + 商业险，险别有车损 | 交商 | 联合单 |
| 商业险，无交强险 | 单商业 | — (非联合单) |
| 其他（仅驾乘意外/全无） | None | None |

> 货车逻辑：联合单 = 交三 + 车损。货车"单交"和"联合单"二选一。

### 第三步：每行过滤器（35 个）

`ROW_FILTERS` 字典：行号 → lambda(vehicle_dict) -> bool

每行独立匹配（不互斥），一辆车可同时被多个行计入。

**关键过滤维度**：
- `is_xt` 行唐地址（地址含"行唐"或证件号前6位=130125）
- `is_yd_id` 异地身份证（证件号前4位≠1301）
- `min_age` 最小年龄 < 25
- `is_xin` 新能源（能源非"燃油/燃气"；兑底：险种含交强 + 车船税=0）
- `is_new` 新车
- `is_guo` 过户
- `is_qiye` 企业车（车辆使用性质含"非营业企业"）
- `is_xingyong` 营运（车辆使用性质含"营业"且不含"家庭"且不含"非营业"）
- `truck_sub` 货车车型（普货/箱货/仓栏/多用途/自卸）
- `load_lt_2` 2吨以下（核载质量 < 2 吨，>40 时除以 1000 换算），仅货车行 R24-R37 需要
- `xianzhong_kc` 客车险种（单交/交三/交商/单商业）
- `xianzhong_hc` 货车险种（单交/联合单/None）
- `has_jq` / `has_sy` 该车 险种是否含 交强/商业 (用于 R36/R37 不限)

### 第四步：保司计数 & Top12

按 `first_sn`（首条 rec 的保险公司简称）累计 Counter，most_common(12) 填入 E-P。

后缀去除：财险 / 保险 / 在线 / 联合。

后置规则（PUSH_BACK）：人保 / 平安 出现时一定在结果中且排在末位。

黑名单剔除（EXCLUDE_SNS）：默认 `{前海}`。黑名单保司的车辆在 `load_data()` 阶段从源 xlsx 里直接剔除，不参与分类与计数；CLI 可用 `--exclude <名>` 追加。

### 第五步：填模板（zip-level XML 操作）

`fill_via_zip` 直接改 sheet1.xml 里的 E-L 单元格，保留模板的合并、边框、底色。

## 边界处理

- 某行无匹配车辆 → 该行 E-L 留空（不填 `-`）
- 数据源不存在 → 报错"数据文件不存在"
- 车辆未匹配任何行 → 该车不计入
