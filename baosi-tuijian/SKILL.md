# baosi-tuijian · 车险保司推荐模板

> **职责单一**: 从零构建一份 41 行 × 12 列的 xlsx 模板. **A-D 列内置字段硬编码** (能源/过户/属性/险种), **E-L 列 8 个推荐位留空** 待业务方填入.
> 不含排序/计算/退保感知/填推荐/公司名映射 — 那些是业务方的活, 不是模板的活.
>
> **业务扩展点**: 通过 `header_notes` 给表头单元格加 ⓘ 图标 + 鼠标悬停 tooltip (例如 "保费司不同返点不同"). 不传 = 跟原版 100% 一致. 详见下方 "业务扩展点: 表头备注" 章节.

---

## 用途

- 输出一份 `保司推荐-{日期}.xlsx` 空模板 (Sheet 1 = 41 模板行 × 12 列)
- A-D 列: 内置固定内容 (A 类别, B 过户/属性, C 新旧, D 险种)
- E-L 列: 8 个推荐位 (主推 1-5 + 推荐 6-8), 留空, 调用方按业务自行填入

**典型流程**:
1. 跑 `python3 scripts/build_template.py [输出路径]` 生成空模板
2. 调用方 (人 / 脚本 / Hermes) 按业务算法算 39 模板行的 top 8 公司
3. 调 `openpyxl` 直接往 E-L 列写公司名 (或自己包一层 fill 函数)
4. 输出最终 `保司推荐-{日期}.xlsx` 推微信 / 推 PDF

## 一键使用

### 1. CLI 生成空模板
```bash
python3 ~/.openclaw/workspace/skills/baosi-tuijian/scripts/build_template.py [输出.xlsx]
# 默认输出: ./政策推荐表.xlsx

# 带表头备注
python3 build_template.py 模板.xlsx --notes '{"E":"保费司不同返点不同","I":"限本地公司"}'
```

### 2. Python 库用法
```python
from build_template import build
from openpyxl import load_workbook

# 生成空模板
wb = build()
wb.save('保司推荐-2026-06-12.xlsx')

# 生成带表头备注的模板
wb = build(header_notes={"E": "保费司不同返点不同", "I": "限本地公司"})
wb.save('保司推荐-2026-06-12.xlsx')

# 二次加载 + 填推荐位
wb = load_workbook('保司推荐-2026-06-12.xlsx')
ws = wb['推荐表']
ws['E2'] = '平安'   # 行 2 (通用/行唐地址) 主推 1
ws['F2'] = '人保'   # 主推 2
# ... E-L 共 8 列
wb.save('保司推荐-2026-06-12.xlsx')
```

## 业务扩展点: 表头备注 (header_notes)

**何时用**: 某个推荐位列 (主推1-5/推荐6-8) 有**业务规则/注意事项**需要标注时.
- 例 1: E 列 (主推1) 有"保费司不同返点不同"业务策略
- 例 2: I 列 (主推5) "限本地公司"
- 例 3: J 列 (推荐6) "货车专用"

**效果**: 该列表头单元格尾部追加 ⓘ 图标 + 鼠标悬停时显示完整备注 (openpyxl Comment).

### 不传 header_notes → 跟原版 100% 一致 (无 ⓘ, 无 Comment)

### 两种调用形式

**简单形式** (同一备注应用到 row1 + row26 两行表头):
```python
from build_template import build
wb = build(header_notes={
    "E": "保费司不同返点不同",
    "I": "限石家庄本地公司",
})
```

**嵌套形式** (分别指定 row1 / row26 的备注):
```python
wb = build(header_notes={
    "row1": {"E": "仅适用乘用车段", "I": "限本地公司"},
    "row26": {"J": "货车专用规则"},
})
```

**CLI 用法**:
```bash
python3 build_template.py 模板.xlsx --notes '{"E":"保费司不同返点不同","I":"限本地"}'
```

### 设计要点

- **ⓘ 图标** = Unicode `\u24d8` (Circled Latin Small Letter I, 跟 macOS/Win 资源管理器 "Get Info" 图标一致)
- **Comment 通过 openpyxl `Comment(text, "JARVIS Ω")` 实现**, Excel/WPS 打开时鼠标悬停显示
- **不传 notes = 跟原版 cell value 字符串完全一致**, self-check 100% 通过 (因为多了 comment 不影响 value)
- **只影响表头单元格** (E1-L1, E26-L26). 数据行 (2-25, 27-41) 不动.

### 边界
- key 必须是 `A-L` 列字母, 不在范围内的列会被静默忽略
- value 是字符串, 不是字符串的 value 在嵌套形式下会被忽略
- 不传 / 传 `None` / 传空 dict 都视为"无备注"
- Comment author 固定为 "JARVIS Ω", 改不了 (skill 不暴露这个)
